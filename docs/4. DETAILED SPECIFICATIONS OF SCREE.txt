Maturity Date.

Screen 6: Multi-Signatory Web Review Portal (Director SMS Journey)
Route: /signatory/review/:token

Standalone view designed for directors opening an approval SMS link on mobile/desktop without logging into the main borrower portal.

Displays full breakdown of requested drawdown (Initiated by, Supplier, Amount, Tenor, Total Repayable).

Three Distinct Action Paths:

Approve & Sign: Opens full-width canvas signature pad -> Confirms transaction -> Moves drawdown to APPROVED / DISBURSED.

Request Rework: Opens comment drawer -> Director inputs correction notes (e.g., "Reduce amount by 200k") -> Moves drawdown to REWORK state and alerts initiator.

Decline: Rejects application with audit reason.

Screen 7: "My Loans" Portfolio & Dual-Method Repayment
Route: /customer/loans and /customer/repay

Filterable tab navigation: [All], [Active], [Overdue], [Paid Off].

Click loan -> Repay Drawer / Screen:

Select mode: Full Payment vs Partial Payment (with live balance recalculation).

Select Source:

NCBA Account: Fetches customer's T24 accounts, user selects account, enters PIN -> Real-time debit simulation.

M-PESA: Input phone number -> Trigger STK push simulation with countdown loader, handling WRONG_PIN, CANCELLED, TIMEOUT, and SUCCESS with automated retries.

Screen 8: Internal Bank LMS Portal (Maker-Checker Operations)
Route: /admin/lms/*

Dedicated back-office dashboard for bank operations staff.

Features:

Credit Limit Management (Maker-Checker):

Maker View: Search customer, request limit amendment with justificatory memo upload.

Checker View: Approval queue displaying pending amendments with audit trails and Approve/Reject controls.

Portfolio Monitoring: Live table of all facilities across anchors, classification grades (Normal 1-30 DPD, Watch 30-90 DPD, Substandard 90-180 DPD, Loss 360+ DPD), 30% p.a. default penalty calculation.

Core Reconciliations: View T24 FT references matched against mobile repayment transaction hashes.
